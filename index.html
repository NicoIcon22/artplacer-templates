ArtPlacer · Website templates

Four gallery website templates, with ArtPlacer built in

Each template has the full site structure: artists with their own bio, artworks, exhibitions, news, social links and contact pages, plus gallery-wide Exhibitions, News and an Artworks page for selling works, books and objects. Every artwork page carries the ArtPlacer widget, and exhibition pages can embed an ArtPlacer Virtual Exhibition.

Site map (identical in all four templates)

  • Artists

      • Artworks

      • Exhibitions

      • News list
        • News article
      • Social media & external links
      • Contact (with artwork enquiry)
  • Exhibitions: current / upcoming / past filter · Virtual Exhibition (optional)
  • News

  • Contact

ArtPlacer widgets used

Every page that has widgets loads the ArtPlacer script once, before the template code:

<script src="https://widget.artplacer.com/js/script.js"></script>

View in sample room runs the live ArtPlacer Sample Room widget, inserted on each artwork page with:

ArtPlacer.insert({ gallery: "1", type: "2", space: "73591", additional_spaces: "73591,73863,295986", artwork: "701308", unit: "in", catalog: "false", … })

The template's own themed button triggers ArtPlacer's button, and the widget is re-inserted on every page change. View in AR and Try in your room show preview images for now.

Exhibition pages where Virtual Exhibition is enabled:

<iframe width="100%" height="450" src="https://d7mntklkfre1v.cloudfront.net/virtual-exhibitions/?i=22084" frameborder="0" allowfullscreen></iframe>

This hosted preview blocks outside scripts, so the live Sample Room only runs once the files are on a web server, and on a domain the ArtPlacer gallery is authorised for.
